# shadcn skill attribution

The shadcn skill is copied from the `skills/shadcn` directory in [shadcn/ui](https://github.com/shadcn-ui/ui).
The official skills CLI installed its upstream content without changes.
The MIT license and copyright notice are retained in `LICENSE.md`.
The repository keeps one copy, in `.claude/skills/shadcn/`.

`skills-lock.json` at the repository root records the skill source and content hash.

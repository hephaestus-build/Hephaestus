# resolve-review attribution

The severity scale in § 2 and the reply style in § 3 are adapted from the `sol-loop` and
`leaving-pr-comments` skills in [tstack](https://github.com/t3dotgg/tstack).
The attribution callout that `leaving-pr-comments` adds to each comment is left out, because this
repository allows no agent attribution.

### `config.sync`

| Key | Type | Default | Required in object | Constraints |
| --- | --- | --- | --- | --- |
| `config.sync.cooldownMinutes` | integer | `60` | yes | Whole minutes, bound to an application integer. This is the minimum interval between syncs.<br />`minimum: 1. maximum: 1440` |
| `config.sync.runOnStartup` | boolean | `true` | yes | — |
| `config.sync.syncCron` | string | `"0 0 * * * *"` | yes | A Spring cron expression with six fields, seconds first.<br />`pattern: "^\\S+( \\S+){5}$"` |
| `config.sync.timeframeDays` | integer | `7` | yes | Whole days, bound to an application integer. This is the initial sync and reconciliation timeframe.<br />`minimum: 1. maximum: 365` |

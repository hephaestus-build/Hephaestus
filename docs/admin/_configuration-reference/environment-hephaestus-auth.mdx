| `HEPHAESTUS_AUTH_BOOTSTRAP_ADMINS` | `hephaestus.auth.bootstrap-admins` |  | `server` | Identities that become instance admins when they sign in, as `provider:@username` or `provider:subject`. Use the subject where a username can be claimed again. Email addresses are never matched. |
| `HEPHAESTUS_AUTH_BOOTSTRAP_TOKEN` | `hephaestus.auth.bootstrap-token` |  | `server` | Optional token, controlled by the deployment, that recovers an instance without an active admin. A blank value turns off the recovery endpoint. |

| `HEPHAESTUS_AUTH_ISSUER` | `hephaestus.auth.issuer` | `default: http://localhost:${SERVER_PORT}; prod: http://localhost:${SERVER_PORT}` | `server` | Canonical `iss` claim. Its origin is also the public origin of the API and of the webhook receivers that GitLab and Outline registrations name. |
| `HEPHAESTUS_AUTH_PASSKEYS_ADMIN_MAX_AGE` | `hephaestus.auth.passkeys.admin-max-age` | `default: 6h` | `server` | How long one passkey verification opens admin work that a passkey protects. After it, the admin verifies a passkey again; the session itself continues. Sensitive actions keep the shorter `hephaestus.auth.step-up-max-age`. |
| `HEPHAESTUS_AUTH_PASSKEYS_ALLOWED_ORIGINS` | `hephaestus.auth.passkeys.allowed-origins` | `default: http://localhost:${WEBAPP_PORT}; prod: (empty)` | `server` | Browser origins that may register and use passkeys, as a comma-separated list. Each must be an HTTPS origin on the RP ID or one of its subdomains. When it is empty, the origin of the auth issuer is used. |
| `HEPHAESTUS_AUTH_PASSKEYS_INSTANCE_ADMIN_REQUIRED` | `hephaestus.auth.passkeys.instance-admin-required` | `default: false; prod: true` | `server` | Requires a verified passkey sign-in from every instance admin. Workspace and account settings cannot turn this off. |
| `HEPHAESTUS_AUTH_PASSKEYS_RP_ID` | `hephaestus.auth.passkeys.rp-id` | `default: (empty); prod: (empty)` | `server` | WebAuthn relying party ID, the domain that passkeys are bound to. When it is empty, the host of the auth issuer is used. Passkeys registered under one RP ID do not work under another. |
| `HEPHAESTUS_AUTH_PASSKEYS_WORKSPACE_ADMIN_REQUIRED` | `hephaestus.auth.passkeys.workspace-admin-required` | `default: false; prod: false` | `server` | Requires a verified passkey sign-in for workspace administration in every workspace. A workspace cannot turn this off. |
| `HEPHAESTUS_AUTH_STATE_COOKIE_KEY` | `hephaestus.auth.state-cookie-key` | `default: (empty); prod: (empty)` | `server` | Base64-encoded 32-byte AES key that seals the OAuth state and sign-in intent cookies. Required outside development. |

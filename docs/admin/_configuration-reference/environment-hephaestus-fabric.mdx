### `hephaestus.fabric`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_FABRIC_ROOT` | `hephaestus.fabric.root` | `default: /data/git-repos` | `server` | Local directory for the bare Git mirrors and the evidence folders of running reviews. The process must be able to write to it. Its contents are not durable application state. |

### `hephaestus.webhook`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_WEBHOOK_STREAM_ALLOW_DESTRUCTIVE_LIMIT_UPDATES` | `hephaestus.webhook.stream.allow-destructive-limit-updates` | `default: false` | `webhook` | Lets startup apply a limit change that deletes messages that the stream already holds. A smaller bound deletes the excess at once, so the operator must turn this on deliberately. |
| `HEPHAESTUS_WEBHOOK_STREAM_LIMIT_UPDATE_TIMEOUT` | `hephaestus.webhook.stream.limit-update-timeout` | `default: 5m` | `webhook` | How long startup waits for one stream limit update. A smaller bound deletes the excess before the broker answers, so a large stream can take long. It is separate from the consumer request timeout, so a slow update does not delay readiness. |
| `HEPHAESTUS_WEBHOOK_STREAM_MAXBYTESBYSTREAM_GITHUB` | `hephaestus.webhook.stream.max-bytes-by-stream.github` | `default: 10GB` | `webhook` | Storage bounds keyed by stream name that override max-bytes for that stream. The github stream carries most of the traffic. Each entry must be at least 4 times http.max-payload-bytes. |
| `HEPHAESTUS_WEBHOOK_STREAM_MAX_AGE` | `hephaestus.webhook.stream.max-age` | `default: 7d` | `webhook` | Longest time a webhook stream keeps a message, for each stream without an entry in max-age-by-stream. Must be at least duplicate-window. |
| `HEPHAESTUS_WEBHOOK_STREAM_MAX_BYTES` | `hephaestus.webhook.stream.max-bytes` | `default: 1GB` | `webhook` | Storage bound of each webhook stream without an entry in max-bytes-by-stream. At the bound, JetStream deletes the oldest messages to admit new ones. Must be at least 4 times http.max-payload-bytes. |
| `HEPHAESTUS_WEBHOOK_STREAM_STORAGE_BUDGET` | `hephaestus.webhook.stream.storage-budget` | `default: 16GB` | `webhook` | What the broker may hold for all webhook streams together. Keep it at or below the free space on the broker volume. The per-stream bounds must stay inside it, so a full stream refuses messages instead of stopping the broker. |
| `WEBHOOK_ROUTING_PREVIOUS_SECRET` | `hephaestus.webhook.routing.previous-secret` | `default: (empty)` | `server`, `webhook` | Previous routing key that the receiver still accepts during a rotation. Keep it until every hook signed with it is replaced. Requires routing.secret and must differ from it. |
| `WEBHOOK_ROUTING_SECRET` | `hephaestus.webhook.routing.secret` | `default: (empty)` | `server`, `webhook` | Key that signs the webhook token of each GitLab connection and derives the signing secret of each Outline subscription. At least 32 characters, and must differ from the webhook secret. GitLab and Outline webhook registration is skipped when it is unset. |
| `WEBHOOK_SECRET` | `hephaestus.webhook.secret` | `default: (empty)` | `server`, `webhook` | Shared secret that verifies GitHub webhook signatures. The server and webhook roles require at least 32 printable ASCII characters without spaces, also on an instance without GitHub. Must differ from both routing secrets. |

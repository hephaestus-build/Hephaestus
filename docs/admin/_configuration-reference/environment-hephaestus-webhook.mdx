### `hephaestus.webhook`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `WEBHOOK_ROUTING_PREVIOUS_SECRET` | `hephaestus.webhook.routing.previous-secret` | `default: (empty)` | `server` | Previous routing key that the receiver still accepts during a rotation. Keep it until every hook signed with it is replaced. Requires routing.secret and must differ from it. |
| `WEBHOOK_ROUTING_SECRET` | `hephaestus.webhook.routing.secret` | `default: (empty)` | `server` | Key that signs the webhook token of each GitLab connection and derives the signing secret of each Outline subscription. At least 32 characters, and must differ from the webhook secret. GitLab and Outline webhook registration is skipped when it is unset. |
| `WEBHOOK_SECRET` | `hephaestus.webhook.secret` | `default: (empty)` | `server` | Shared secret that verifies GitHub webhook signatures. The server requires at least 32 printable ASCII characters without spaces, also on an instance without GitHub. Must differ from both routing secrets. |

### `hephaestus.contact`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_CONTACT_STARTED_MESSAGES_ENABLED` | `hephaestus.contact.started-messages-enabled` | `default: true` | `server` | Lets Hephaestus send check-ins and updates of its own on this instance. When it is off, Hephaestus sends neither, in any workspace. Answers, results that people asked for and the weekly digest still arrive. |

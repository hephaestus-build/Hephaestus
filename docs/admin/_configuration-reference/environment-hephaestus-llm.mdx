### `hephaestus.llm`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_LLM_DISPLAY_CURRENCY` | `hephaestus.llm.display-currency` | `default: (empty)` | `server` | Code of the second currency in which spend in USD is also shown. Empty shows USD only. |
| `HEPHAESTUS_LLM_EGRESS_PRIVATE_HOSTS` | `hephaestus.llm.egress.private-hosts` | `default: (empty)` | `server` | Model endpoints on private networks that provider base URLs may use, as host names, IP addresses or CIDR ranges. A host name entry lets that name resolve to a private address. A range admits every host name that resolves into it. Only private addresses qualify: loopback, link-local and the known cloud metadata ranges stay blocked. A range wider than /16 (IPv4) or /48 (IPv6), outside the private ranges, or covering this server's own address stops startup. Empty allows public hosts only. |
| `HEPHAESTUS_LLM_EGRESS_PRIVATE_HOSTS_ALLOW_HTTP` | `hephaestus.llm.egress.private-hosts-allow-http` | `default: false` | `server` | Accepts `http://` base URLs whose host is in `private-hosts`. Every other host still needs HTTPS. |
| `HEPHAESTUS_LLM_USAGE_RETENTION` | `hephaestus.llm.usage.retention` | `default: P400D` | `server` | Age from `occurred_at` at which a ledger row is deleted. Operator-tunable because the ledger is accounting data: a commercial or tax retention obligation can run years beyond the default, and the deletion is irreversible. |

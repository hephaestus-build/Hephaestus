### `hephaestus.security`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_SECURITY_CREDENTIAL_ENCRYPTION_KEY` | `hephaestus.security.credential-encryption-key` |  | `server` | Active key that encrypts the stored credentials of integration connections. Exactly 32 bytes, so 32 ASCII characters. Required in production. |
| `HEPHAESTUS_SECURITY_CREDENTIAL_ENCRYPTION_KEY_VERSION` | `hephaestus.security.credential-encryption-key-version` |  | `server` | Positive version number stored with each credential that the active credential key encrypts. Must differ from prior-credential-encryption-key-version. |
| `HEPHAESTUS_SECURITY_CREDENTIAL_ROTATION_ENABLED` | `hephaestus.security.credential-rotation-enabled` |  | `server` | Re-encrypts stored credentials with the active credential key in batches on the server role. Requires both the active and the prior credential key. |
| `HEPHAESTUS_SECURITY_ENCRYPTION_KEY` | `hephaestus.security.encryption-key` |  | `server`, `migration` | Key that encrypts sensitive values at rest, such as login provider secrets, LLM connection keys and JWT signing keys. Exactly 32 bytes, so 32 ASCII characters. Required in production. |
| `HEPHAESTUS_SECURITY_ENCRYPTION_ROTATION_ENABLED` | `hephaestus.security.encryption-rotation-enabled` |  | `server` | Seals each stored system secret again with the active encryption key on the server role. Requires both the active and the prior encryption key. |
| `HEPHAESTUS_SECURITY_PRIOR_CREDENTIAL_ENCRYPTION_KEY` | `hephaestus.security.prior-credential-encryption-key` |  | `server` | Previous credential key, still used to decrypt credentials stored under its version during a key rotation. Exactly 32 bytes. Set it together with prior-credential-encryption-key-version. |
| `HEPHAESTUS_SECURITY_PRIOR_CREDENTIAL_ENCRYPTION_KEY_VERSION` | `hephaestus.security.prior-credential-encryption-key-version` |  | `server` | Version number of the previous credential key. Set it together with prior-credential-encryption-key. |
| `HEPHAESTUS_SECURITY_PRIOR_ENCRYPTION_KEY` | `hephaestus.security.prior-encryption-key` |  | `server` | Previous encryption key, still used to open values that it sealed during a key rotation. Exactly 32 bytes. Each sealed value names its key by an identifier derived from the key, so no version is set. |

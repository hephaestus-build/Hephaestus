### `hephaestus.sandbox`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_SANDBOX_KUBERNETES_NAMESPACE` | `hephaestus.sandbox.kubernetes.namespace` | `default: (empty)` | `server` | The dedicated Kubernetes namespace for this release's sandbox claims, Pods and warm pools. |
| `SANDBOX_API_MAX_CONNECTIONS` | `hephaestus.sandbox.gateway.max-connections` | `default: 4096` | `server` | Most connections that the sandbox gateway holds open at once. Up to 100 further connections wait in the operating system's queue, and the rest fail. A review at its most calls in flight holds 170, and a normal review about 54 (estimated). |
| `SANDBOX_API_PORT` | `hephaestus.sandbox.gateway.port` | `default: 8081` | `server` | Port of the extra server connector that serves the sandbox gateway. The gateway API answers only on this port. The value 0 binds a free port at start. |
| `SANDBOX_MAX_CONCURRENT` | `hephaestus.sandbox.max-concurrent-containers` | `default: 5` | `server` | The most review sandboxes this server runs at once. |

### `hephaestus.sandbox`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_SANDBOX_KUBERNETES_CONVERSATION_PRIORITY_CLASS` | `hephaestus.sandbox.kubernetes.conversation-priority-class` |  | `server` | The PriorityClass of the conversation tools Pods. Blank gives none. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_GATEWAY_PROBE_SERVICE` | `hephaestus.sandbox.kubernetes.gateway-probe-service` | `default: (empty)` | `server` | DNS name of the Service that the isolation probe proves a sandbox's route through. Empty where no such Service exists, as with a server outside the cluster. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_NAMESPACE` | `hephaestus.sandbox.kubernetes.namespace` | `default: (empty)` | `server` | The namespace of every sandbox Pod and Job. The installation owns it alone, so everything in it of the sandbox kinds is this installation's. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_NODE_SELECTOR` | `hephaestus.sandbox.kubernetes.node-selector` | `default: (empty)` | `server` | The node labels of sandbox Pods, as a JSON object. Empty allows any node. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_POD_IP` | `hephaestus.sandbox.kubernetes.pod-ip` | `default: (empty)` | `server` | The address where sandboxes reach this server: its Pod IP, or the k3d host address during development. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_POD_NAME` | `hephaestus.sandbox.kubernetes.pod-name` | `default: (empty)` | `server` | This server's Pod name, or its worktree identity during host development. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_PROBE_INTERVAL` | `hephaestus.sandbox.kubernetes.probe-interval` | `default: 15m` | `server` | How often the isolation probe runs again after the server's start. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_REVIEW_PRIORITY_CLASS` | `hephaestus.sandbox.kubernetes.review-priority-class` |  | `server` | The PriorityClass of review and probe Pods, below the conversations': a review is an attempt that runs again, a conversation is a person waiting. Blank gives none. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_RUNTIME_CLASS_NAME` | `hephaestus.sandbox.kubernetes.runtime-class-name` | `default: (empty)` | `server` | The RuntimeClass of every sandbox Pod. Blank selects the cluster's default. It must support user namespaces. A missing or incompatible class fails the isolation probe. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_SECCOMP_PROFILE` | `hephaestus.sandbox.kubernetes.seccomp-profile` | `default: (empty)` | `server` | The shipped `sandbox/agent-seccomp-profile.json` as a Localhost profile, relative to the kubelet's seccomp directory. Blank selects `RuntimeDefault`. |
| `HEPHAESTUS_SANDBOX_KUBERNETES_TOLERATIONS` | `hephaestus.sandbox.kubernetes.tolerations` | `default: (empty)` | `server` | The tolerations of sandbox Pods, as a JSON array of Kubernetes tolerations. Empty tolerates no taint. |
| `SANDBOX_API_MAX_CONNECTIONS` | `hephaestus.sandbox.gateway.max-connections` | `default: 4096` | `server` | Most connections that the sandbox gateway holds open at once. Up to 100 further connections wait in the operating system's queue, and the rest fail. A review at its most calls in flight holds 170, and a normal review about 54 (estimated). |
| `SANDBOX_API_PORT` | `hephaestus.sandbox.gateway.port` | `default: 8081` | `server` | Port of the extra server connector that serves the sandbox gateway. The gateway API answers only on this port. The value 0 binds a free port at start. |
| `SANDBOX_MAX_CONCURRENT` | `hephaestus.sandbox.max-concurrent-containers` | `default: 5` | `server` | The most review sandboxes this server runs at once. |

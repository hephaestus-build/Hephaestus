### `hephaestus.features`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `BROWSER_FAULT_REPORTS` | `hephaestus.features.flags.browser-fault-reports` | `default: false` | `server` | Lets the browser of each reader, signed in or not, report the failures that it met to the server's logs and metrics. In the EU, turning it on can require consent or a documented legal basis. |
| `PAGE_EXPERIENCE_METRICS` | `hephaestus.features.flags.page-experience-metrics` | `default: false` | `server` | Lets the browser of a signed-in reader measure how fast each visit loads and responds and report it to the page experience metrics. In the EU, turning it on can require consent or a documented legal basis. |

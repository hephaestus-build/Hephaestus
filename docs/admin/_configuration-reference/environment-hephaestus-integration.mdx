### `hephaestus.integration`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `GH_APP_CLIENT_ID` | `hephaestus.integration.github.app.client-id` | `default: (empty)` | `server` | The App's client ID, which exchanges the code GitHub returns when an installation requests user authorization. |
| `GH_APP_CLIENT_SECRET` | `hephaestus.integration.github.app.client-secret` | `default: (empty)` | `server` | The client secret of the GitHub App. Set it together with the client ID. |
| `GH_APP_ID` | `hephaestus.integration.github.app.id` | `default: 0; prod: 0` | `server`, `worker` | ID of the GitHub App. The value 0 turns GitHub App mode off. Must not be negative. |
| `GH_APP_INSTALLATION_URL` | `hephaestus.integration.github.app.installation-url` | `default: (empty)` | `server` | URL where users install the GitHub App, such as https://github.com/apps/my-app/installations/new. |
| `GH_APP_PRIVATE_KEY` | `hephaestus.integration.github.app.private-key` | `default: (empty); prod: (empty)` | `server`, `worker` | PEM-encoded private key of the GitHub App, as an inline value. |
| `GITLAB_DEFAULT_SERVER_URL` | `hephaestus.integration.gitlab.default-server-url` | `default: ${hephaestus.auth.login-providers.gitlab.base-url}` | `server`, `worker`, `migration` | The GitLab server URL for a workspace that names no server of its own. |
| `GITLAB_ENABLED` | `hephaestus.integration.gitlab.enabled` | `default: false` | `server`, `worker` | Turns on the GitLab integration, which syncs GitLab groups and projects and delivers feedback on merge requests. |
| `HEPHAESTUS_INTEGRATION_OUTLINE_ALLOWED_ORIGINS` | `hephaestus.integration.outline.allowed-origins` | `default: (empty)` | `server`, `webhook`, `worker` | Outline origins that workspace connections and Outline sign-in may use, as a comma-separated list such as https://wiki.example.com. Each must be an HTTPS origin without a path. Hephaestus refuses every Outline address that is not listed. |
| `HEPHAESTUS_INTEGRATION_OUTLINE_ENABLED` | `hephaestus.integration.outline.enabled` | `default: false` | `server`, `webhook`, `worker` | Turns on the Outline integration, which lets workspaces connect Outline and syncs its documents. Each workspace admin still connects their workspace separately. |
| `HEPHAESTUS_INTEGRATION_SLACK_ENABLED` | `hephaestus.integration.slack.enabled` | `default: false` | `server`, `webhook`, `worker` | Master toggle for the Slack integration (OAuth install, lifecycle listeners, outbound messaging). |
| `HEPHAESTUS_INTEGRATION_SLACK_SIGNING_SECRET` | `hephaestus.integration.slack.signing-secret` | `default: (empty)` | `server`, `webhook` | Signing secret of the Slack app, which verifies inbound Events API and interactivity requests. Required when the Slack integration is on, or the server and webhook roles do not start. |

### `hephaestus.feedback-retention`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_FEEDBACK_RETENTION` | `hephaestus.feedback-retention` | `default: P400D` | `server` | The age at which conversation entries, feedback and practice results are erased. An entry counts from when it was written, feedback from its delivery or its creation when never delivered, and a result from when it was recorded, once no kept feedback cites it. |

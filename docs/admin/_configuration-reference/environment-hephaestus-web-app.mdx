### `hephaestus.web-app`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `SECURITY_CONTACT` | `hephaestus.web-app.security-contact` | `default: (empty)` | `server` | The deployment's contact for `/.well-known/security.txt` (RFC 9116): one `mailto:`, `https://` or `tel:` URI. Empty serves no file. |

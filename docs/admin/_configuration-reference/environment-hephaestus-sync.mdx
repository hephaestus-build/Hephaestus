### `hephaestus.sync`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `MONITORING_RUN_ON_STARTUP` | `hephaestus.sync.run-on-startup` | `prod: true` | `server` | Whether to trigger a sync run immediately when the application starts. |
| `MONITORING_SYNC_COOLDOWN_IN_MINUTES` | `hephaestus.sync.cooldown-minutes` | `prod: 60` | `server` | Minimum minutes between consecutive sync operations. |
| `MONITORING_SYNC_CRON` | `hephaestus.sync.cron` | `prod: 0 0 * * * *` | `server` | Cron expression for scheduled sync execution. |
| `MONITORING_TIMEFRAME` | `hephaestus.sync.timeframe-days` | `prod: 7` | `server` | Number of days to look back when synchronizing pull requests. |
| `NATS_DURABLE_CONSUMER_NAME` | `hephaestus.sync.nats.durable-consumer-name` | `default: hephaestus; prod: hephaestus` | `server`, `webhook` | Durable consumer name for JetStream subscriptions (empty for ephemeral). |
| `NATS_PASSWORD` | `hephaestus.sync.nats.password` | `default: (empty)` | `server`, `webhook` | Password that the NATS connection authenticates with. Set it together with the user name, or leave both empty. |
| `NATS_SERVER` | `hephaestus.sync.nats.server` | `prod: (empty)` | `server`, `webhook` | NATS server URL (e.g., nats://localhost:4222). |
| `NATS_USERNAME` | `hephaestus.sync.nats.username` | `default: (empty)` | `server`, `webhook` | User name that the NATS connection authenticates with. Set it together with the password, or leave both empty. |

### `hephaestus.mcp`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_MCP_ENABLED` | `hephaestus.mcp.enabled` | `default: false` | `server` | Lets workspace admins connect MCP clients, such as Claude Code, to their workspaces. When it is off, the MCP endpoints, their metadata and the MCP authorization endpoints answer 404. |

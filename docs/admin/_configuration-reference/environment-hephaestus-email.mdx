### `hephaestus.email`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_EMAIL_FROM` | `hephaestus.email.from` | `default: (empty)` | `server` | The sender address in the envelope and the header. Required when `spring.mail.host` is set. The relay must be allowed to send for its domain through SPF and DKIM. |
| `HEPHAESTUS_EMAIL_FROM_NAME` | `hephaestus.email.from-name` | `default: Hephaestus` | `server` | The display name shown next to `from`. |
| `HEPHAESTUS_EMAIL_REPLY_TO` | `hephaestus.email.reply-to` | `default: (empty)` | `server` | The address that receives human replies. When it is blank, replies go to the sender address. |

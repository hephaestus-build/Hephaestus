### `hephaestus.consent`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_RESEARCH_ORGANIZATION` | `hephaestus.consent.research-organization` | `default: (empty)` | `server` | Name of the organization that runs a research study on this instance. When it is set, first-login setup and account settings ask users for research consent. At most 255 characters. |

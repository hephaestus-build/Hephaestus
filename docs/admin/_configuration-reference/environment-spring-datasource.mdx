### `spring.datasource`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `DATABASE_PASSWORD` | `spring.datasource.password` | `prod: (empty)` | `server`, `migration` | Login password of the database. |
| `DATABASE_URL` | `spring.datasource.url` | `prod: (empty)` | `server`, `migration` | JDBC URL of the database. |
| `DATABASE_USERNAME` | `spring.datasource.username` | `prod: (empty)` | `server`, `migration` | Login username of the database. |
| `SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE` | `spring.datasource.hikari.maximum-pool-size` |  | `server`, `migration` | Most PostgreSQL connections that one process holds in its pool. The sizing guide, in its Database connections section, derives the server's value. Keep the sum over all processes below the PostgreSQL connection limit. |
| `SPRING_DATASOURCE_HIKARI_MINIMUM_IDLE` | `spring.datasource.hikari.minimum-idle` |  | `server`, `migration` | The minimum number of idle database connections that this process tries to keep in its pool. |

### `hephaestus.public-activity`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_PUBLIC_ACTIVITY_ENABLED` | `hephaestus.public-activity.enabled` |  | `server` | Allows public activity pages on this instance until an instance admin changes the switch in the admin console. Each workspace must also opt in. |
| `HEPHAESTUS_PUBLIC_ACTIVITY_REPOSITORY_VISIBILITY_MAX_AGE` | `hephaestus.public-activity.repository-visibility-max-age` |  | `server` | How recently a sync must have confirmed that a repository is public for its work to appear on public activity pages. Must be positive. Accepts 48h, 2d, PT48H. |

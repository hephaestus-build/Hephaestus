### `hephaestus.release`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `DEPLOYMENT_ENVIRONMENT` | `hephaestus.release.environment` | `default: local` | `server`, `migration` | The name of this deployment, such as `production`. The webapp, log lines and traces use the same name. |
| `HEPHAESTUS_IMAGE_APPLICATION_SERVER` | `hephaestus.release.image` | `default: (empty)` | `server` | The digest reference of the image that this container started from. It is empty outside a deployment from a release lock. |
| `HEPHAESTUS_RELEASE_CHECK_ENABLED` | `hephaestus.release.check-enabled` | `default: true` | `server` | Whether the server role may ask GitHub for the newest published release. |
| `HEPHAESTUS_RELEASE_COMMIT` | `hephaestus.release.commit` | `default: (empty)` | `server`, `migration` | The source commit that the release lock names. It is empty outside a deployment from a release lock. |

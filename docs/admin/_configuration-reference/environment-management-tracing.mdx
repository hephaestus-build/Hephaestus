### `management.tracing`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `TRACING_OTLP_ENABLED` | `management.tracing.export.otlp.enabled` | `default: false` | `server` | Whether auto-configuration of tracing is enabled to export OTLP traces. |
| `TRACING_SAMPLING_PROBABILITY` | `management.tracing.sampling.probability` | `default: 0.0` | `server` | Probability in the range from 0.0 to 1.0 that a trace will be sampled. |

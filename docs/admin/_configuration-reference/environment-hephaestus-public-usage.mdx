### `hephaestus.public-usage`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_PUBLIC_USAGE_ENABLED` | `hephaestus.public-usage.enabled` |  | `server` | Turns on Hephaestus in numbers, the public page of instance totals released once each half-year, until an instance admin changes the switch with PUT /api/admin/settings/public-usage. |

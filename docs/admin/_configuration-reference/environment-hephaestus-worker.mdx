### `hephaestus.worker`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_WORKER_CAPACITY_MENTOR_MAX` | `hephaestus.worker.capacity.mentor-max` |  | `worker` | Number of conversation turns this worker runs at once. Accepts an integer or auto, which means 8. |
| `HEPHAESTUS_WORKER_DRAIN_TIMEOUT` | `hephaestus.worker.drain.timeout` |  | `worker` | How long a stopping worker waits for running practice reviews to finish before it cancels them. Set 0s to cancel them at once. |

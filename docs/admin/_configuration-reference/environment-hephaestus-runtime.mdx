### `hephaestus.runtime`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `HEPHAESTUS_RUNTIME_SERVER_ENABLED` | `hephaestus.runtime.server.enabled` | `default: true` | `webhook` | Runs the server role, which serves the API, syncs provider work and delivers feedback. Turn it off in a worker-only or webhook-only container. |
| `HEPHAESTUS_RUNTIME_WEBHOOK_ENABLED` | `hephaestus.runtime.webhook.enabled` | `default: true` | `server`, `webhook` | Runs the webhook role, which receives provider webhooks and publishes them to NATS JetStream. Under the prod profile, this role needs NATS. |
| `HEPHAESTUS_RUNTIME_WORKER_ENABLED` | `hephaestus.runtime.worker.enabled` | `default: true` | `server`, `webhook` | Runs the worker role, which runs sandboxed practice reviews and conversation turns. Only a container with this role may mount the Docker socket. |

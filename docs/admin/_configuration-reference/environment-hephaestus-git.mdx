### `hephaestus.git`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `GIT_CHECKOUT_ENABLED` | `hephaestus.git.enabled` | `default: false` | `server` | Keeps local Git mirrors of monitored repositories, which practice reviews read code from. Turn it on wherever agent jobs run. Without it, the practice review health check reports out of service. |
| `GIT_MAX_CACHE_BYTES` | `hephaestus.git.max-cache-bytes` | `default: 10737418240` | `server` | This process's eviction budget on its Git volume. Set it to the volume's size minus one snapshot bound for each review and each conversation load that the process runs at once; the Helm chart does this. When everything on the volume uses more than 80 % of it, Hephaestus deletes the mirrors it used least recently. A deleted mirror costs one full fetch at its next capture. |
| `GIT_MAX_SNAPSHOT_BYTES` | `hephaestus.git.max-snapshot-bytes` | `default: 8589934592` | `server` | The most disk that one snapshot may use: the checkout and reachable history of a review, a conversation's context load, or a scan. Hephaestus refuses a larger repository whole and does not capture part of it. |

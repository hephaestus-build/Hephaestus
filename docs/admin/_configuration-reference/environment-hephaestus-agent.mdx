### `hephaestus.agent`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `AGENT_ENABLED` | `hephaestus.agent.enabled` | `default: false` | `server`, `worker` | Turns on agent jobs, which run practice reviews. The server role submits jobs and the worker role runs them, so set it on both. |
| `AGENT_MAX_ACTIVE_COMPOSITIONS` | `hephaestus.agent.max-active-compositions` | `default: 4` | `worker` | Most compositions whose inputs one worker loads at once. Additional attempts wait without loading composition inputs. This does not reduce review sandbox capacity. |
| `AGENT_MAX_CONCURRENT_COMPOSITIONS` | `hephaestus.agent.max-concurrent-compositions` | `default: 16` | `worker` | The most review attempts one worker runs at once. An attempt composes its feedback after its sandbox ends, and then it holds no sandbox slot. Thus this setting bounds the concurrent compositions. The sandbox slots still bound the attempts that hold a sandbox. A value below the sandbox slots also lowers the sandboxes in use. |
| `HEPHAESTUS_AGENT_IMAGE_REFERENCE` | `hephaestus.agent.image.reference` |  | `server`, `webhook`, `worker` | Image reference used by Pi practice sandboxes and the Hephaestus container. Production must be digest-pinned (registry/path@sha256:\<64 lowercase hex\>). |
| `HEPHAESTUS_AGENT_IMAGE_REQUIRE_DIGEST` | `hephaestus.agent.image.require-digest` |  | `server`, `webhook`, `worker` | Refuses startup unless the agent image reference is pinned by digest. |
| `HEPHAESTUS_AGENT_SANDBOX_GATEWAY_URL` | `hephaestus.agent.sandbox.gateway-url` |  | `worker` | The gateway address that a claim passes to its sandbox, such as `http://10.43.0.12:8081`. The server resolves the host to an address when it creates a claim, so the sandbox needs no DNS. Empty where this process creates no claim. |
| `HEPHAESTUS_AGENT_SANDBOX_WARM_POOLS_ACTION` | `hephaestus.agent.sandbox.warm-pools.action` |  | `worker` | The warm pool that an action task's sandbox is claimed from. |
| `HEPHAESTUS_AGENT_SANDBOX_WARM_POOLS_CONVERSATION` | `hephaestus.agent.sandbox.warm-pools.conversation` |  | `worker` | The warm pool that a conversation's sandbox is claimed from. |
| `HEPHAESTUS_AGENT_SANDBOX_WARM_POOLS_REVIEW` | `hephaestus.agent.sandbox.warm-pools.review` |  | `worker` | The warm pool that a review's sandbox is claimed from. |

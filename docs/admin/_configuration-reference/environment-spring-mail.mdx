### `spring.mail`

| Variable | Setting | Application default | Containers | Description |
| --- | --- | --- | --- | --- |
| `SPRING_MAIL_HOST` | `spring.mail.host` | `default: (empty)` | `server` | SMTP server host. For instance, 'smtp.example.com'. |
| `SPRING_MAIL_PASSWORD` | `spring.mail.password` | `default: (empty)` | `server` | Login password of the SMTP server. |
| `SPRING_MAIL_PORT` | `spring.mail.port` | `default: 587` | `server` | SMTP server port. |
| `SPRING_MAIL_PROPERTIES_MAIL_SMTP_AUTH` | `spring.mail.properties[mail.smtp.auth]` | `default: true` | `server` | Additional JavaMail Session properties. |
| `SPRING_MAIL_PROPERTIES_MAIL_SMTP_SSL_ENABLE` | `spring.mail.properties[mail.smtp.ssl.enable]` | `default: false` | `server` | Additional JavaMail Session properties. |
| `SPRING_MAIL_PROPERTIES_MAIL_SMTP_STARTTLS_ENABLE` | `spring.mail.properties[mail.smtp.starttls.enable]` | `default: true` | `server` | Additional JavaMail Session properties. |
| `SPRING_MAIL_PROPERTIES_MAIL_SMTP_STARTTLS_REQUIRED` | `spring.mail.properties[mail.smtp.starttls.required]` | `default: true` | `server` | Additional JavaMail Session properties. |
| `SPRING_MAIL_USERNAME` | `spring.mail.username` | `default: (empty)` | `server` | Login user of the SMTP server. |

The instance catalog holds the practices and practice groups that workspaces can add.
It starts with the Hephaestus defaults.
Use this procedure to include or exclude entries, add instance entries, and decide on updates to the defaults.
Workspace admins add practices from the catalog in their workspace, as [Practices](/user/practices) describes.

## Before you start

You need the instance admin role.
The catalog is at **Instance administration → Practices → Practice catalog**.

## Include or exclude an entry

1. Open **Practice catalog**.
2. Open **More actions** on a practice or a group.
3. Select **Exclude from workspaces** or **Include for workspaces**.
4. If Hephaestus asks you to confirm, read which practices the change also affects, and confirm.

Workspace admins can no longer add an excluded entry.
An excluded group also excludes its practices.
Existing workspace copies do not change.
To list only one state, filter by **Included** or **Excluded**.

## Add or edit an entry

1. Select **Create practice** or **Create group**.
   To change an entry, open **More actions**, then select **Edit practice** or **Edit group**.
2. Fill in the form. The practice form is the editor that workspaces use, as [Practices](/user/practices#create-a-practice) describes.
3. Save the entry.

Saving updates the instance catalog.
Existing workspace copies do not change.
Each workspace with a copy gets the change as a catalog update that its admins accept or decline.

To change the order that new workspaces see, drag groups and practices in the tree, or use **Move up** and **Move down**.

## Decide on an update to a Hephaestus default

An entry that uses a Hephaestus default takes each release's update automatically, until you customize it.
A customized entry shows **Hephaestus update available** when a release changes its default.

1. Open the entry.
2. Select **Review Hephaestus update**.
3. Compare your saved version with the update.
4. Select **Apply Hephaestus update**, or **Keep saved version**.

A default that a release removes shows **Removed from Hephaestus defaults**.
Select **Keep saved version as custom** to keep it as an instance entry, or exclude it from workspaces.
To return a customized entry to the default, select **Restore Hephaestus default**.

## Check that it worked

1. In a workspace, open **Administration → Practices → Practice setup**.
2. Select **Show catalog**.
3. Check that an included entry appears and an excluded entry does not.

## Undo

- To reverse an exclusion, select **Include for workspaces** on the entry.
- To reverse a customization, select **Restore Hephaestus default** on the entry.

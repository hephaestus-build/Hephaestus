---
title: Move from Compose to the Helm chart
description: Move an existing 0.95.0 installation to Kubernetes without changing its application version.
page_type: how-to
---

The deployment move uses release `0.95.0` on both sides.
Do not change the application version and deployment in one step.

## Before you start

Use the signed release assets and instructions of the installed version.
Do not use files from the current release to run the old deployment.
Rehearse the move and recovery on an isolated copy before the outage.

## Move the installation

1. Upgrade the Compose installation to `0.95.0` with its versioned upgrade instructions.
2. Follow the [0.95.0 deployment move](https://github.com/hephaestus-build/Hephaestus/blob/v0.95.0/docs/admin/compose-to-kubernetes.mdx).
   That guide owns the backup, writer stop, data move, isolation and rollback sequence.
3. Apply `0.95.1` after the move succeeds.
4. Install its reconciler tooling before upgrading to the chart-only release.
   Use the [0.95.1 tooling instructions](https://github.com/hephaestus-build/Hephaestus/blob/v0.95.1/docs/admin/pull-based-deployment.mdx#install).
5. Follow [Upgrade from 0.x to 1.0](./upgrade-to-1-0) for the stopped cutover.

## Check that it worked

Before changing the application version, complete the versioned move's acceptance checks.
Confirm that only the chart deployment owns the data.
Keep the verified pre-move recovery set until the move passes those checks.
If the move fails, use that guide's rollback procedure before restoring traffic.

After the move, use [Kubernetes](./kubernetes) for installation and upgrades.

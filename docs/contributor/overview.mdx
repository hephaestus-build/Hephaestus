Hephaestus is maintained by the Applied Education Technologies (AET) team at TUM. It gives developers practice feedback on pull requests, merge requests, and issues, and includes Heph, a conversational AI mentor. This guide covers the codebase and development workflow, from local setup to production releases.

## Repository layout

```text
Hephaestus/
├── webapp/                    # React + Vite front-end (public UI)
├── server/                    # Maven reactor
│   ├── application/           # Spring Boot application — server, worker, and webhook roles
│   └── generated-clients/     # Generated GitHub, GitLab, and Outline transports
├── docs/                      # Docusaurus site (this documentation)
└── scripts/                   # Tooling (ERD generation, migrations, utilities)
```

The webhook receiver lives under `integration/core/webhook/` in the application module and runs
in its own container in production — [Runtime roles](../admin/runtime-roles#monolith-vs-split-pod).

and human workflow; when they disagree with executable configuration, generated API output, or tests,
fix the prose in the same pull request.

## Where the architecture decisions live

The ADRs are **not on this site**, on purpose. They live in the repository under
[`docs/decisions/`](https://github.com/hephaestus-build/Hephaestus/tree/main/docs/decisions), indexed by
[`decisions/README.md`](https://github.com/hephaestus-build/Hephaestus/blob/main/docs/decisions/README.md) —
they are written against internal class names and are amended by the same PR that changes the code,
so their reader already has the repository open. The same applies to `docs/runbooks/`,
`docs/auth-architecture.md` and `docs/auth-glossary.md`.

Two rules when you touch them:

- **Link them by absolute GitHub URL** from any page on this site. A relative `../decisions/…` link
  resolves to nothing here and fails the docs build (`onBrokenMarkdownLinks: 'throw'`).
- **An ADR records a decision, not a fix log.** A bug you fixed afterwards goes in a changeset;
  amend an ADR only when the decision or one of its consequences actually changed.

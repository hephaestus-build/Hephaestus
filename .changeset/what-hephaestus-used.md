Each answer in Ask Hephaestus now has **What Hephaestus used**. Open it to see what the answer cited, which documents about your work, repositories and files it read, which searches it ran, and what it could not open. Hephaestus builds the list from what the answer's turn recorded. The list names no tool, file path or internal ID, and it says so when an answer recorded nothing.

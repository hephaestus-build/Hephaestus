Asking for another review of unchanged work no longer reviews it again. A practice keeps its observation when the practice, its model and everything it reads are unchanged, so the request makes no model call for it. If that holds for every practice, the review starts no sandbox. The review says which observations it kept from the last review. Feedback is not sent again for an observation that was kept. A `/hephaestus review` comment on a GitLab merge request now gets an answer in its thread when no feedback answers it: when nothing changed since the last review, and when the request is refused, with the reason.

The Chrome extension lets you talk with Heph about the pull request, merge request or issue you are viewing, in Chrome's side panel beside the page. Choose **Ask Heph** in the practice review. Your first message starts with a visible line naming the work, and nothing is sent until you press Send. You can stop a reply, try again, start a new conversation, or continue the same conversation in Hephaestus. If you chose No AI, or Heph is not set up for you, the panel says so in the same words as the web app.

**Operators:** nothing to configure. The extension now declares Chrome's `sidePanel` permission, and the same Heph models, AI choices, consent and budgets apply as in the web app.

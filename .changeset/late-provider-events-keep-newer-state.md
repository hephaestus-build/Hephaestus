A late or redelivered provider event no longer brings back older state. A milestone keeps its newer title, state and due date. A GitHub review thread that you unresolved stays unresolved when the earlier "resolved" event arrives late, so feedback about unresolved review threads reads the current thread. An older Slack opt-out that arrives after you opted back in no longer undoes your opt-in or erases the messages you shared after it.

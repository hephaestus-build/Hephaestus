The workspace admin lists of practice reviews, work, observations, and feedback load more rows when you scroll to the end of a list. They no longer show numbered pages. If more rows do not load, the rows that you have stay on the screen and you can retry. You can also use **Show more** at the end of a list with the keyboard. Each row shows one time, also when a new review starts while you scroll.

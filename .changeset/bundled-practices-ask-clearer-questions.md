The bundled practices ask clearer questions, so a review records "not met" less often when the work is fine. A source that was not captured, such as a linked issue or the discussion, now leaves a question open instead of counting against the work; a close call gets the lower severity; and each practice now gives major severity only for the consequences its own standard names. A pull request with a single commit is still checked for bundled work, and its testing section being empty no longer reads as "no way to check the change" when the description, the linked issue or the README already says how.

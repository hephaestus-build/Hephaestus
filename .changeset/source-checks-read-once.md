Your Practice page and the review problems list open faster. Before showing your cards and the problems on a page, Hephaestus checks that it may still read the work behind them. It now does that check for all the work on the page at once: each repository and each person is checked once, however many pull requests or issues share them. Every item still passes every check, including the erasure and consent checks. Before, each pull request or issue was checked on its own.

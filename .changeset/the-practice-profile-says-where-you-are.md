On the Practice profile, every panel you open now says where it sits: a short path above its
title names the page and the levels behind it, and pressing a step in that path takes you back to
it. The same path sits above the editors in the workspace's Practice setup and the instance's
Practice catalog, so a practice or group you are editing says which list it came from. The
practice panel no longer repeats its group beside the standing, since the path already names it.
The action item on a feedback card no longer shows a square box that looked like something to
tick; it now carries the same icon as the card's status badge, a circle while the feedback is open
and a green check once three pieces of work in a row came back clean, or once you mark it
addressed.

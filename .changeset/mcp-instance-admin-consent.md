Instance admins can now connect an MCP client, such as Claude Code, to a workspace that they administer as an admin or owner. Where the instance requires a passkey from its instance admins, the consent page asks for a passkey confirmation first, as for any workspace admin under a passkey policy. The client does only the workspace admin work that the admin approved, in that one workspace, and never acts as an instance admin. The consent page no longer refuses instance admins.

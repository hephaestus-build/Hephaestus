Feedback comments on GitHub and GitLab no longer notify a person, team or group that the text names with @. The name appears as code, also when Hephaestus edits an earlier comment. HTML and comments in feedback text appear as written text, images appear as links, link notes that only show on hover are left out, and a line that starts with a slash no longer runs a GitLab quick action.

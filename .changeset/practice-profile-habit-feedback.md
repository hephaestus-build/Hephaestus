The Practice profile now calls its feedback cards **Habit feedback** and says that each one is about a shortcoming seen on more than one piece of your work. A practice whose Habit feedback tab reads 0 no longer suggests that feedback went missing: the tab says so and points to **Observations**, which list each review of a single pull request, merge request or issue. Feedback posted on that work stays on it.

You can now keep practices in a practice repository without the API. **Practice setup** shows the **Practice repository**: set it to one of your monitored repositories, with an optional directory, change it, or unset it. A practice edited in Hephaestus offers **Move to repository**. After you confirm, Hephaestus reads the practice's folder from the default branch, and the practice becomes read-only in Hephaestus. When Hephaestus refuses the move, the dialog shows the reason, and for a folder that is not valid, lists each problem with its file and, where known, its line and column. Each of these changes asks for a recent sign-in.

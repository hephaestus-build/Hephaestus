"hephaestus": minor
---

Ask Hephaestus now uses its own name everywhere: in the API, in metrics, in settings and in the database, as the 0.95 release notes announced. "Mentor" now means only a person. A workspace's choice of model for practice reviews or Ask Hephaestus is now called a model assignment, and **AI models** names its row **Ask Hephaestus** instead of **Conversations**. Practice profiles say "observations" where they said "assessments".

**API clients:** the conversation endpoints moved from `/api/workspaces/{slug}/mentor/…` to `/api/workspaces/{slug}/conversation/…`, with the schemas, operation IDs and fields that the 0.95 notes list. Model assignments moved from `/api/workspaces/{slug}/agents` to `/api/workspaces/{slug}/model-assignments`, with the schemas `ModelAssignment` and `ModelAssignmentRequest` and the purpose type `ModelPurpose`. These values changed as announced: the speaker `HEPH` is `ANSWER`, the feedback location `HEPH` is `APP`, the wait reason `FREE_HEPH` is `CAPACITY`, the purpose `MENTOR` is `CONVERSATION`, the usage source `MENTOR_TURN` is `CONVERSATION_TURN` and the notification `MENTOR_DIGEST` is `WEEKLY_DIGEST`. The problem types `mentor-lease-lost`, `mentor-turn-stopped`, `mentor-refused`, `mentor-rejected` and `agent-binding-slot-mismatch` are now `conversation-lease-lost`, `conversation-turn-stopped`, `conversation-refused`, `conversation-rejected` and `model-assignment-slot-mismatch`. New configuration audit entries for model assignments have the type `MODEL_ASSIGNMENT`. Entries written earlier keep `AGENT_BINDING`, because the audit log never changes. The workspace fields `practiceReviewAutoTriggerEnabled` and `practiceReviewManualTriggerEnabled` are now `practiceReviewEventEnabled` and `practiceReviewRequestEnabled`. In a personal-data export, the conversation stores are named `conversation`, `conversation_entry`, `conversation_turn`, `conversation_entry_feedback_copy` and `conversation_entry_tool_result_copy`.

Slack answers and their feedback buttons keep working.

Links to `/w/{slug}/mentor` no longer redirect. Hephaestus has linked to `/w/{slug}/conversation` since 0.95.

**Operators:** Install this change in the stopped window before the 1.0.0 cut. Stop every runtime role before the migration, then start only the upgraded roles. The migration renames the conversation and model-assignment tables, so an old server cannot run beside a new one. The metrics `mentor.turn.*` (Prometheus `mentor_turn_*`) and `mentor.live.streams` are now `conversation.turn.*` and `conversation.live.streams`, the `surface` label value `mentor` is `conversation`, the email delivery `kind` tag `mentor_digest` is `weekly_digest`, the rate-limit `bucket` tag `mentor-turns` is `conversation-turns`, and the log events `mentor.turn.ended`, `heph.turn.tool_call` and `heph.turn.model_call` are `conversation.turn.ended`, `conversation.turn.tool_call` and `conversation.turn.model_call`. The shipped alert rules and dashboards already use the new names, so update your own queries. Outside the chart, rename `HEPHAESTUS_MENTOR_TURN_*` and `HEPHAESTUS_RATE_LIMIT_MENTOR_TURNS_*` to `HEPHAESTUS_CONVERSATION_TURN_*` and `HEPHAESTUS_RATE_LIMIT_CONVERSATION_TURNS_*`, and `hephaestus.mentor.*` settings to `hephaestus.conversation.*`. `HEPHAESTUS_MENTOR_CONVERSATION_RETENTION` stays retired: use `HEPHAESTUS_FEEDBACK_RETENTION`. The chart values do not change.

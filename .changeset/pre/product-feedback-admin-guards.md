When erasure leaves product feedback issues on GitHub for a maintainer, instance admins now get one email per cleanup run that lists every issue, not one email per issue. An issue that needs a retry first is announced in a later email. Hephaestus now refuses to remove the private repository while a public issue can still be made private or still waits to move there. You can replace it with another private repository. **Resolve** in the list of reports not on GitHub now refuses a report that is filed on GitHub, or on its way there.

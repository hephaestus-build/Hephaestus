Code in feedback on GitHub and GitLab now appears as code, and emphasis as emphasis. Before, the feedback showed the backtick characters around code, such as `` `false` ``. Names, references, commits, links, e-mail addresses, web addresses and math in the feedback appear as code, so a comment notifies no one. Only a reference that an administrator sets up for an issue tracker can still become a link.

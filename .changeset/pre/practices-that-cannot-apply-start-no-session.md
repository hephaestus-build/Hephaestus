A review no longer starts a model session for five practices when the captured change proves they cannot apply. Three practices about a merge record Does not apply on work that has not merged. **Keep the test suite honest** records it when no changed path or line marks a test. **Change dependencies deliberately** records it when no changed file can declare a dependency. Requested reviews of open pull requests save those sessions. An author of a practice can now also choose the condition **The work has merged** under Applies when. **API clients:** the definition options can now list the condition kind `MERGED`, and a definition can carry `merged: true` in `appliesWhen`.

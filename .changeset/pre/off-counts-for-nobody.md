Observations that a review records while a practice's feedback mode is **Off** no longer count toward anyone's standing, on the Practice profile, in Practices across the workspace or in conversations. Workspace admins still see them in Practice reviews. Turning feedback on later does not make them count, so you can watch a new practice with feedback Off before it affects anyone's standing. Observations recorded before this release keep counting as before.

On **Practice reviews**, the link from a practice's observations and the link from a failed practice script now say **Open in Practice setup** for a practice edited in the practice repository, and open its read-only view instead of an editor it does not have. If another admin moves a practice to the practice repository while you edit it, your changes stay on screen to copy, the editor says why, and saving turns off. **Edit in Hephaestus** there lets you save them again.

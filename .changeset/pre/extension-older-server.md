The browser extension now says when your Hephaestus server is too old for it, in place of a report that cannot load.

Chrome updates the extension on its own, so upgrade the server to keep up. The extension needs version 1.0.0 or newer, and version 1.0.0-rc.1 counts as too old. `/.well-known/hephaestus.json` now also names the running version.

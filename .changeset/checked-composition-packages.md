Practice feedback is checked as a complete package before it is accepted for publication. Checking a draft does not send or save its feedback. Publication checks permissions and evidence again, and approval still applies where required.

Pull and merge request feedback uses one review submission for its summary and notes. Interrupted private drafts can be resumed without posting separate discussions, and uncertain submissions are read back before any retry. Existing feedback keeps its provider references for withdrawal and correction.

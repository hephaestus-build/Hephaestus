Workspace admins can connect an MCP client, such as Claude Code, to a workspace and let it read and configure the workspace's practices. The client sees practice settings, review settings, members' provider logins and review status, and never source code, observations, feedback or conversations. The endpoint stays off until an operator sets the new optional `HEPHAESTUS_MCP_ENABLED=true`.

Instance administrators can inspect the running build and deployment-reported image digests and check for stable releases from the overview. Update information distinguishes failed, stale, disabled and never-performed checks, highlights published schema migrations, and links to verified upgrade and recovery instructions. Set `HEPHAESTUS_RELEASE_CHECK_ENABLED=false` to disable outbound release checks, including manual checks, on air-gapped installations.

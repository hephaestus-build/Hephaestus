Hephaestus no longer describes tests or code that it did not read in a long conversation. Before, a long answer about a pull request could lose the files it had just read to an automatic summary and then state what a test covers or how a call behaves from memory. Now it keeps what it read for the whole answer, and it says when it has not read a test or the code a change calls.

In a long conversation, an answer about your work no longer loses the files that Hephaestus just read when the conversation is summarised to make room, unless that one answer outgrows the AI model's context on its own. Hephaestus also says when it has not read a test or the code that a change calls, instead of describing them. Before, a long answer about a pull request could describe a test that does not exist.

Operators can file product feedback automatically as GitHub issues in their own public and private repositories.
GitHub filing is off by default. Nothing leaves an instance until its operator names a repository.
Reporters choose whether an issue can become public and have five minutes to keep it private before filing.
Privacy and security checks keep other reports private. Admin email remains the fallback when a report is not on GitHub.

To enable filing, first update your legal text to name GitHub and the model provider and record the lawful bases.
Install the instance’s GitHub App on both repositories with Issues: read and write.
The private repository must be private and have the same owner as the public repository.
Choose a model and a daily draft limit. Use Pause to stop new filing while withdrawal and erasure cleanup continue.

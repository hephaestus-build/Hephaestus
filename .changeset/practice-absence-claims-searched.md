Feedback on whether a pull request ships tests, keeps its tests honest, and documents its public API is withheld less often. A statement about the change itself, such as "the diff contains no test file" or "no test in the same change", no longer counts as a claim about the whole repository that needs a search. When a review checks whether anything else in the repository uses or tests the changed code, it now gets a ready search for the changed names, so a claim that nothing uses them is backed by that search.

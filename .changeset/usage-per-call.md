---
"hephaestus": minor
---

Each model call of a review or a conversation answer now has its own usage row, written when the call starts and measured when it ends. Spend counts toward a budget as soon as a call ends, not when its review or answer ends. The usage by practice now shows the exact cost of each practice's own calls, and **Reviews** counts reviews, not review attempts.

Every model call now has an output limit, so each call has a most it can cost: its upper bound. A call counts toward a budget at its upper bound while it runs. A call whose usage Hephaestus cannot measure, such as a call without a usage block, a call cut off before its answer, or a call still open when its worker stopped, is now recorded without a cost and keeps counting at its upper bound. Before, some of these calls left no record, and others paused a capped budget for the rest of the month. **AI usage** shows the upper bound apart from the confirmed spend, as "Up to $X more from N calls whose usage was not measured", and a review's cost that includes one reads "Up to".

**Operators:** stop every role before you upgrade; see the migration guide. Set **Max output tokens** or **Context window** on every chat model and on every model for practice-script decisions: the proxy refuses a call to a chat model without either with status 400. It clamps the output limit of each chat request to the model's limit, and writes the limit into a request that names none. Multiple completion choices count toward the call's upper bound. The proxy accepts text inputs and client-run tools; it refuses images, audio, files and provider-stored inputs because their token counts cannot be bounded by the request size. An OpenAI-compatible server that ignores the output-limit field can write past a call's upper bound. A capped purse now starts a call only while the call's upper bound fits in what is left of the cap, and refuses it otherwise as a reached cap. The `llm.budget.exhausted` counter counts measured spend only. A call of a model without a price, or of a priced reranking model, has no upper bound and still pauses a capped purse. The new column `llm_usage_event.cost_bound_usd` holds each call's upper bound. The `review_job_attempt_usage`, `review_job_attempt_charge`, `review_job_script_usage` and `mentor_turn_attempt_usage` tables and the usage columns of `review_job` and `mentor_turn` are gone: `llm_usage_event` holds each call. The repricing pass now prices unpriced usage of every month, oldest first, not only of the current month. The metrics `llm_proxy_usage_late_settled_total`, `llm_proxy_usage_accumulate_superseded_total`, `llm_proxy_usage_mentor_failure_total` and `llm_proxy_usage_mentor_superseded_total` are gone. `llm_proxy_usage_accumulate_failure_total` now counts a call whose measurement could not be written, and `llm_usage_unverifiable_total` also counts the open calls that the end of a run settles.
